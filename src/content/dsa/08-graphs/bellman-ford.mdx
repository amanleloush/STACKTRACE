## Problem
Single-source shortest paths in a weighted graph that **may contain negative edges**. Also detect negative cycles reachable from the source.

## Interview-ready explanation
Bellman-Ford finds single-source shortest paths when edges can be negative. I set the source's distance to 0 and every other distance to infinity, then relax every edge V−1 times. Relaxing edge u→v with weight w means: if `dist[u] + w < dist[v]`, update `dist[v]`. A shortest path without cycles has at most V−1 edges, so after V−1 rounds every distance is final, and I can stop early if a whole round changes nothing. Then I do one more round: if any edge can still be relaxed, a negative cycle is reachable from the source. It's O(V·E) time and O(V) space, slower than Dijkstra, but it handles negative weights.

**One-liner:** Relax every edge V−1 times to get shortest paths even with negative weights; if a V-th pass still improves a distance, there's a reachable negative cycle: O(V·E).

## Intuition
A shortest path in a graph with V nodes uses at most V−1 edges (otherwise it revisits a node and you can shortcut). So **relax every edge V−1 times** and every shortest distance will settle. The invariant: **after k full passes, `dist[v]` is at most the length of the shortest path from source to v using at most k edges** (it can already be better, because in-place updates can chain several edges within one pass — which is why the K-stops variant must copy `dist` between passes). A V-th pass that still improves any distance proves a negative cycle is reachable.

## Algorithm
Init `dist[source] = 0`, infinity elsewhere. Loop V−1 times: for every edge `(u, v, w)`, if `dist[u] + w < dist[v]`, set `dist[v] = dist[u] + w`. Run one more pass; any further improvement signals a negative cycle.

```cpp
// edges[i] = {u, v, w}. Returns dist (INT_MAX = unreachable), or {} if a negative
// cycle is reachable from src.
vector<int> bellmanFord(int n, const vector<vector<int>>& edges, int src) {
    const int INF = INT_MAX;
    vector<int> dist(n, INF);
    dist[src] = 0;
    for (int i = 0; i < n - 1; ++i) {
        bool updated = false;
        for (auto& e : edges) {
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != INF && dist[u] + w < dist[v]) {  // skip unreachable u
                dist[v] = dist[u] + w;
                updated = true;
            }
        }
        if (!updated) break;  // early exit when stable
    }
    // negative-cycle check
    for (auto& e : edges) {
        int u = e[0], v = e[1], w = e[2];
        if (dist[u] != INF && dist[u] + w < dist[v]) return {};  // neg cycle reachable from src
    }
    return dist;
}
```

```java
class Solution {
    // edges[i] = {u, v, w}. Returns dist (Integer.MAX_VALUE = unreachable), or an empty
    // array if a negative cycle is reachable from src.
    static int[] bellmanFord(int n, int[][] edges, int src) {
        final int INF = Integer.MAX_VALUE;
        int[] dist = new int[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;
        for (int i = 0; i < n - 1; i++) {
            boolean updated = false;
            for (int[] e : edges) {
                int u = e[0], v = e[1], w = e[2];
                if (dist[u] != INF && dist[u] + w < dist[v]) {  // skip unreachable u
                    dist[v] = dist[u] + w;
                    updated = true;
                }
            }
            if (!updated) break;  // early exit when stable
        }
        // negative-cycle check
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != INF && dist[u] + w < dist[v]) return new int[0];  // neg cycle
        }
        return dist;
    }
}
```

```python
def bellman_ford(n, edges, src):
    dist = [float('inf')] * n
    dist[src] = 0
    for _ in range(n - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break                       # early exit when stable
    # negative-cycle check
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None                 # neg cycle reachable from src
    return dist
```

## Walkthrough
Example: 5 nodes `S, A, B, C, D`; directed edges `S→A(6), S→B(7), A→B(8), A→C(5), B→C(-3), B→D(9), C→D(2)`. Source = S.

1. **Init.** `dist = [S:0, A:∞, B:∞, C:∞, D:∞]`.
2. **Pass 1.** Relax in edge order: `S→A` sets `A=6`, `S→B` sets `B=7`, `A→B` keeps `B=7` (6+8≥7), `A→C` sets `C=11`, `B→C` sets `C=4` (7−3), `B→D` sets `D=16`, `C→D` sets `D=6` (4+2). Result: `[0, 6, 7, 4, 6]`.
3. **Pass 2.** No edge improves, so `updated` stays `False` and the loop breaks early, skipping the remaining passes and going straight to the cycle check.
4. **Cycle-check pass.** Run every edge once more; nothing relaxes, so **no negative cycle reachable from S**.
5. **End.** Final shortest paths: `S=0, A=6, B=7, C=4, D=6`.

## Complexity

time **O(V · E)** · space **O(V)**

## Pitfalls
- **Early exit** when a full pass changes nothing — common test cases settle long before V−1.
- **Negative cycle detection** is a *separate* V-th pass; don't claim cycles from intermediate passes.
- **Guard unreachable nodes** — Python's `float('inf')` is safe, but in Java/C++ with `INT_MAX` as infinity, `dist[u] + w` overflows, and "infinity plus a negative weight" looks like a real distance. Skip edges whose `dist[u]` is still infinity.
- **SPFA** (Shortest Path Faster Algorithm) is a queue-based Bellman-Ford that's fast in practice but worst-case identical.
- **K-edge variant** (problem 787) — run exactly K+1 passes; cap path edges and snapshot `dist` between passes to avoid relaxing twice in one pass.
