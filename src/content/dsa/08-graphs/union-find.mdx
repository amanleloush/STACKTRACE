## Problem
Maintain a partition of N elements under two operations: `find(x)` returns the representative of x's group, and `union(x, y)` merges x's and y's groups. Detect whether two elements are in the same group in near-constant time.

## Interview-ready explanation
This is Union-Find, also called a disjoint-set union (DSU). Each group is stored as a tree of parent pointers, and the root is the group's representative. `find` walks up to the root and, with path compression, re-points every node it passed straight at the root; `union` finds both roots and, with union by rank, hangs the lower-rank root under the higher-rank one. With both optimizations, any sequence of operations costs O(α(n)) amortized per operation, where α is the inverse Ackermann function and is at most 4 for any practical n, using O(n) space.

**One-liner:** Union-Find keeps each group as a parent-pointer tree and, with path compression plus union by rank, answers find and union in O(α(n)) amortized time, which is effectively constant.

## Intuition
Each group is a tree; the root is the representative. **Path compression** flattens the tree on every `find` so future queries are nearly direct. **Union by rank** always hangs the tree with the smaller rank (an upper bound on its height) under the one with the larger rank, keeping height at O(log n). The invariant: **every element's `parent` chain eventually reaches the root of its current group**, and the amortized cost per op is O(α(n)) — the inverse Ackermann function, effectively constant for any n you'll see.

## Algorithm
Store `parent[i]` (self-rooted initially) and `rank[i]` (initially 0). `find` recursively follows parents while compressing. `union` finds both roots, attaches the lower-rank one under the higher-rank one.

```cpp
// `union` is a C++ keyword, so the merge is `unite`
struct DSU {
    vector<int> parent, rank;

    DSU(int n) : parent(n), rank(n, 0) {
        for (int i = 0; i < n; ++i) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]);  // path compression
        return parent[x];
    }

    bool unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry)
            return false;                 // already joined
        if (rank[rx] < rank[ry])
            swap(rx, ry);
        parent[ry] = rx;
        if (rank[rx] == rank[ry])
            rank[rx] += 1;
        return true;
    }
};
```

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])    # path compression
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False                                  # already joined
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True
```

## Walkthrough
Example: N=6. Operations: union(0,1), union(2,3), union(0,2), find(3), union(4,5), find(1), find(5).

1. union(0,1): parent[1]=0, rank[0]=1.
2. union(2,3): parent[3]=2, rank[2]=1.
3. union(0,2): both rank 1 → parent[2]=0, rank[0]=2. Now group {0,1,2,3}.
4. find(3): 3 → 2 → 0; compress so parent[3]=0, parent[2]=0. Returns 0.
5. union(4,5): parent[5]=4. find(1)=0, find(5)=4 → different groups; final group count = 2.

## Complexity

time **O(α(n)) per op (amortized)** · space **O(n)**

## Pitfalls
- **Both optimizations matter** — union by rank alone is O(log n) per op and path compression alone is O(log n) amortized; together you get α(n). Always do both.
- **Iterative `find`** avoids recursion-depth blowups if you skip union by rank (trees can then be O(n) deep) — two-pass: find the root, then re-walk to compress.
- **Union by size** is equivalent to rank — pick one and stay consistent.
- **Per-group metadata** (count, sum, etc.) is easy: maintain `size[root]` and update on `union`.
- **DSU doesn't support split** — to undo unions use a rollback DSU (union by rank, no path compression, keep a change stack) or a link-cut tree.
