## Problem
Find all **strongly connected components** (SCCs) of a directed graph — maximal sets of nodes where every pair has a path each way. The undirected sibling: find **bridges** (edges whose removal disconnects the graph).

## Interview-ready explanation
This is Tarjan's SCC algorithm: a single DFS with discovery times and low-link values. Each node gets `disc[u]`, the time it was first visited, and `low[u]`, the smallest discovery time it can reach through its DFS subtree plus one edge to a node that is still on the stack. I push nodes on a stack as I visit them; after exploring u's neighbors, if `low[u] == disc[u]`, then u is the root of an SCC, and I pop the stack down to u to emit that component. Each node and edge is processed once, so it is O(V + E) time and O(V) extra space for the arrays, the stack and the recursion.

**One-liner:** Tarjan runs one DFS tracking discovery time and low-link per node, and whenever a node's low-link equals its own discovery time it pops that node's SCC off a stack, in O(V + E).

## Intuition
DFS assigns each node a **discovery time** `disc[u]`. We also track `low[u]` — the smallest `disc` reachable from u's DFS subtree by following at most one extra edge to a node that is still on the stack. When `low[u] == disc[u]`, **u is the root of an SCC**: nothing in its subtree can reach an ancestor of u, so the nodes sitting above u on the stack (its subtree minus any SCCs already popped) are exactly that SCC. The invariant: **after DFS returns from u, `low[u]` is correct, and an unfinished node remains on the SCC stack iff it hasn't been emitted yet**.

## Algorithm
DFS from every unvisited node. On entry, set `disc[u] = low[u] = timer++` and push u on the stack. For each neighbor v: if unvisited, recurse and `low[u] = min(low[u], low[v])`; if v is on the stack, `low[u] = min(low[u], disc[v])`. After exploring, if `low[u] == disc[u]`, pop until u — that's an SCC.

```cpp
vector<vector<int>> tarjanScc(int n, const vector<vector<int>>& graph) {
    vector<int> disc(n, -1), low(n, 0);
    vector<char> on_stack(n, false);
    vector<int> stack;
    vector<vector<int>> sccs;
    int timer = 0;

    function<void(int)> dfs = [&](int u) {
        disc[u] = low[u] = timer++;
        stack.push_back(u);
        on_stack[u] = true;
        for (int v : graph[u]) {
            if (disc[v] == -1) {
                dfs(v);
                low[u] = min(low[u], low[v]);
            } else if (on_stack[v]) {
                low[u] = min(low[u], disc[v]);
            }
        }
        if (low[u] == disc[u]) {
            vector<int> comp;
            while (true) {
                int w = stack.back();
                stack.pop_back();
                on_stack[w] = false;
                comp.push_back(w);
                if (w == u) break;
            }
            sccs.push_back(comp);
        }
    };

    for (int u = 0; u < n; ++u) {
        if (disc[u] == -1) dfs(u);
    }
    return sccs;
}
```

```java
class Solution {
    private int[] disc, low;
    private boolean[] onStack;
    private Deque<Integer> stack;
    private List<List<Integer>> sccs;
    private List<List<Integer>> graph;
    private int timer;

    public List<List<Integer>> tarjanScc(int n, List<List<Integer>> graph) {
        disc = new int[n];
        Arrays.fill(disc, -1);
        low = new int[n];
        onStack = new boolean[n];
        stack = new ArrayDeque<>();
        sccs = new ArrayList<>();
        this.graph = graph;
        timer = 0;
        for (int u = 0; u < n; u++) {
            if (disc[u] == -1) dfs(u);
        }
        return sccs;
    }

    private void dfs(int u) {
        disc[u] = low[u] = timer++;
        stack.push(u);
        onStack[u] = true;
        for (int v : graph.get(u)) {
            if (disc[v] == -1) {
                dfs(v);
                low[u] = Math.min(low[u], low[v]);
            } else if (onStack[v]) {
                low[u] = Math.min(low[u], disc[v]);
            }
        }
        if (low[u] == disc[u]) {
            List<Integer> comp = new ArrayList<>();
            while (true) {
                int w = stack.pop();
                onStack[w] = false;
                comp.add(w);
                if (w == u) break;
            }
            sccs.add(comp);
        }
    }
}
```

```python
def tarjan_scc(n, graph):
    disc = [-1] * n
    low = [0] * n
    on_stack = [False] * n
    stack, sccs = [], []
    timer = [0]

    def dfs(u):
        disc[u] = low[u] = timer[0]; timer[0] += 1
        stack.append(u); on_stack[u] = True
        for v in graph[u]:
            if disc[v] == -1:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif on_stack[v]:
                low[u] = min(low[u], disc[v])
        if low[u] == disc[u]:
            comp = []
            while True:
                w = stack.pop(); on_stack[w] = False
                comp.append(w)
                if w == u:
                    break
            sccs.append(comp)

    for u in range(n):
        if disc[u] == -1:
            dfs(u)
    return sccs
```

## Walkthrough
Example: 6 nodes `A–F`, directed edges `A→B, B→C, C→A, B→D, D→E, E→D, E→F`.

1. **Descend A→B→C.** DFS from A: assign `A: 0/0`, push. Tree-edge to B: `B: 1/1`, push. Tree-edge to C: `C: 2/2`, push.
2. **Back-edge closes {A,B,C}.** `C→A` and A is on-stack → `low[C] = min(2, disc[A]=0) = 0`. Returning to B: `low[B] = min(1, low[C]=0) = 0`.
3. **Branch into D→E, then back-edge.** Tree-edge `B→D`: `D: 3/3`, push. Tree-edge `D→E`: `E: 4/4`, push. Back-edge `E→D` (D on stack) → `low[E] = min(4, 3) = 3`.
4. **Pop {F}, then pop {D,E}.** Tree-edge `E→F`: `F: 5/5`, push. F has no outgoing edges → `low[F] == disc[F]` → pop SCC **{F}**. Return to E (`low[E]=3`), return to D: `low[D] = min(3, 3) = 3` and `low[D] == disc[D]` → pop SCC **{E, D}**.
5. **Pop {A,B,C} and finish.** Return to B (`low[B]=0`), return to A: `low[A] = 0 == disc[A]` → pop SCC **{C, B, A}**. Three SCCs total: `{A,B,C}`, `{D,E}`, `{F}`.

## Complexity

time **O(V + E)** · space **O(V)**

## Pitfalls
- **`on_stack` is required** — without it, you'd treat cross-edges into already-finished SCCs as back-edges and merge wrongly.
- **`disc[v]` vs `low[v]`** on the back-edge branch — use `disc[v]` (Tarjan's specification). For SCCs, `low[v]` still gives the right components, but the same shortcut breaks the articulation-point variant, so learn `disc[v]`.
- **Recursion depth** — Python's default limit is 1000 frames, so a DFS path longer than about 1000 nodes crashes. Raise the limit or convert to an iterative DFS for big inputs.
- **For bridges** (undirected), track `parent` and check `low[v] > disc[u]` on the edge u-v; don't go back to the parent edge.
- **Kosaraju** (two DFS passes on G and reverse-G) is an alternative SCC algorithm — often easier to remember in an interview but slightly slower in constant factor.
