## Problem
Sort fixed-width integers (or strings) in linear time when keys are too sparse for counting sort.

## Interview-ready explanation
LSD radix sort sorts fixed-width keys one digit at a time, starting from the least significant digit, using a stable counting sort for each digit. Because each pass is stable, keys that tie on the current digit keep the order set by the earlier, less significant digits, so after the last pass the keys are fully sorted. Time is O(d · (n + k)), where `d` is the number of digits and `k` is the base, and space is O(n + k). When `d` is fixed (for example 4 passes of 8 bits for 32-bit integers) that is linear in n.

**One-liner:** Stable counting sort on each digit from least to most significant: O(d · (n + k)), which is linear in n for fixed-width keys.

## Intuition
Run counting sort on the **least-significant digit first**, then the next digit, then the next — `d` passes total. Because each pass uses a stable counting sort, keys with the same current digit stay in the order established by earlier (less-significant) passes. **Invariant**: after pass `i`, the array is correctly sorted by the bottom `i` digits. After `d` passes the entire key is sorted. For 64-bit integers in base 256 that's 8 passes regardless of n — total cost O(8n) which is linear in n.

## Algorithm
Iterate digits from least to most significant, stable-sorting on each.

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        return radixSort(nums, 10);
    }

private:
    vector<int> radixSort(vector<int> a, int base) {
        if (a.empty())
            return a;
        int lo = *min_element(a.begin(), a.end());
        for (int& x : a) x -= lo;                // shift to non-negative
        int maxV = *max_element(a.begin(), a.end());
        long long exp = 1;
        while (exp <= maxV) {
            a = countingByDigit(a, exp, base);
            exp *= base;
        }
        for (int& x : a) x += lo;
        return a;
    }

    vector<int> countingByDigit(const vector<int>& a, long long exp, int base) {
        vector<int> cnt(base, 0);
        for (int v : a) cnt[(v / exp) % base]++;
        for (int i = 1; i < base; ++i) cnt[i] += cnt[i - 1];
        vector<int> out(a.size(), 0);
        for (int k = (int)a.size() - 1; k >= 0; --k) {  // reversed(a)
            int v = a[k];
            int d = (int)((v / exp) % base);
            cnt[d]--;
            out[cnt[d]] = v;
        }
        return out;
    }
};
```

```java
class Solution {
    public int[] sortArray(int[] nums) {
        return radixSort(nums, 10);
    }

    private int[] radixSort(int[] nums, int base) {
        if (nums.length == 0)
            return nums;
        int lo = Integer.MAX_VALUE;
        for (int x : nums) lo = Math.min(lo, x);
        int[] a = new int[nums.length];
        for (int i = 0; i < a.length; i++) a[i] = nums[i] - lo;  // shift to non-negative
        int maxV = 0;
        for (int x : a) maxV = Math.max(maxV, x);
        long exp = 1;
        while (exp <= maxV) {
            a = countingByDigit(a, exp, base);
            exp *= base;
        }
        for (int i = 0; i < a.length; i++) a[i] += lo;
        return a;
    }

    private int[] countingByDigit(int[] a, long exp, int base) {
        int[] cnt = new int[base];
        for (int v : a) cnt[(int) ((v / exp) % base)]++;
        for (int i = 1; i < base; i++) cnt[i] += cnt[i - 1];
        int[] out = new int[a.length];
        for (int k = a.length - 1; k >= 0; k--) {  // reversed(a)
            int v = a[k];
            int d = (int) ((v / exp) % base);
            cnt[d]--;
            out[cnt[d]] = v;
        }
        return out;
    }
}
```

```python
def radix_sort(a, base=10):
    if not a: return a
    lo = min(a)
    a = [x - lo for x in a]              # shift to non-negative
    max_v = max(a)
    exp = 1
    while exp <= max_v:
        a = counting_by_digit(a, exp, base)
        exp *= base
    return [x + lo for x in a]

def counting_by_digit(a, exp, base):
    cnt = [0] * base
    for v in a: cnt[(v // exp) % base] += 1
    for i in range(1, base): cnt[i] += cnt[i - 1]
    out = [0] * len(a)
    for v in reversed(a):
        d = (v // exp) % base
        cnt[d] -= 1
        out[cnt[d]] = v
    return out
```

## Walkthrough
The widget sorts `[170, 45, 75, 90, 802, 24, 2, 66]` in base 10 (10 buckets per pass):

1. **Pass 0 — ones digit (10⁰).** Each value drops into bucket `value % 10`. Bucket `d=0` collects `[170, 90]`, `d=2` collects `[802, 2]`, `d=5` collects `[45, 75]`, and so on. Flatten left-to-right → `[170, 90, 802, 2, 24, 45, 75, 66]`.
2. **Pass 1 — tens digit (10¹).** Digits of the current array: `7, 9, 0, 0, 2, 4, 7, 6`. Bucket `d=0` gets `[802, 2]`, `d=7` gets `[170, 75]` — note `170` lands before `75` because the previous pass already settled their ones-digit order. Flatten → `[802, 2, 24, 45, 66, 170, 75, 90]`.
3. **Pass 2 — hundreds digit (10²).** Six values have hundreds-digit `0`, one has `1` (`170`), one has `8` (`802`). Bucket `d=0` collects `[2, 24, 45, 66, 75, 90]` in their already-correct relative order.
4. **Stability matters.** Because each per-digit step is stable, ties on the current digit retain the order from the previous (less-significant) pass — that's why earlier work isn't undone.
5. **End.** After flattening pass 2 → `[2, 24, 45, 66, 75, 90, 170, 802]`. Max value 802 has 3 digits, so 3 passes were enough.

> **Properties** — stable: yes. In-place: no.
