## Problem
Sort an array in ascending order using only adjacent swaps.

## Interview-ready explanation
Bubble sort repeatedly walks the array and swaps adjacent elements that are out of order, so after each pass the largest remaining element has "bubbled" to the end. Each pass can stop one position earlier, and if a pass makes no swaps the array is sorted and I stop. It is stable, because equal neighbours are never swapped, and in-place. Time is O(n²) in the worst and average case and O(n) in the best case (already sorted, thanks to the early exit); space is O(1).

**One-liner:** Swap adjacent out-of-order pairs pass after pass until a pass makes no swaps: stable, in-place, O(n²), and O(n) on already-sorted input.

## Intuition
Walk the array left to right; whenever two adjacent elements are out of order, swap them. The largest element "bubbles" to the end on every pass. **Invariant**: after pass `i`, the last `i` elements are in their final sorted positions. After at most `n − 1` passes the entire array is sorted, and if a pass finishes without a swap the array is already sorted.

## Algorithm
Repeated adjacent comparison with an early-exit flag.

```cpp
void bubbleSort(vector<int>& a) {
    int n = (int)a.size();
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; ++j) {       // last i are sorted
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) return;                       // already sorted
    }
}
```

```java
class Solution {
    static void bubbleSort(int[] a) {
        int n = a.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - 1 - i; j++) {   // last i are sorted
                if (a[j] > a[j + 1]) {
                    int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                    swapped = true;
                }
            }
            if (!swapped) return;                   // already sorted
        }
    }
}
```

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):       # last i are sorted
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:                  # already sorted
            return
```

## Walkthrough
Sort `[5, 1, 4, 2, 8]`.

1. Pass 1 compares pairs `(5,1) (5,4) (5,2) (5,8)` — three swaps carry `5` right until it stops next to `8` (the max, already at the end): `[1, 4, 2, 5, 8]`.
2. Pass 2 ignores the trailing `8`, compares 3 pairs and swaps `(4,2)`: `[1, 2, 4, 5, 8]`.
3. Pass 3 makes no swaps — the `swapped` flag stays false, so the algorithm terminates early.
4. Final array: `[1, 2, 4, 5, 8]`. Total: 4 swaps, 9 comparisons.

> **Properties** — stable: yes. In-place: yes.
