## Problem
Given heights of adjacent bars in a histogram, return the area of the largest axis-aligned rectangle that fits inside.

## Interview-ready explanation
I use a monotonic increasing stack of indices. The best rectangle uses some bar's full height and extends left and right until it hits a strictly shorter bar. When the current bar is shorter than the bar on top of the stack, the top bar's right boundary is the current index `i` and its left boundary is the new stack top after popping, so its area is `height × (i − left − 1)`. Appending a 0-height sentinel forces every bar to be popped by the end. Each index is pushed and popped once: O(n) time and O(n) space.

**One-liner:** Keep an increasing stack of bar indices; when a shorter bar arrives, pop and score each popped bar's widest rectangle, bounded by its previous and next smaller bars, in O(n).

## Intuition
The optimal rectangle's height is some bar `a[k]`; its width spans from the **nearest smaller bar on the left of `k`** to the **nearest smaller bar on the right of `k`**, exclusive. If we can compute, for every `k`, those two boundaries in O(n), we just take the max of `a[k] · (right − left − 1)`. A monotone **increasing** stack of indices does exactly that: when a new bar shorter than the top arrives, the top has its right boundary (the new index) and its left boundary (the new stack top after pop). **Invariant**: bar heights at the stacked indices are non-decreasing from bottom to top (equal heights stay stacked with the `>` pop test). Pushing a sentinel `0` at the end forces every remaining stacked bar to be resolved.

## Algorithm
Monotone increasing stack of indices + sentinel.

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        vector<int> stk;                     // non-decreasing heights[stk]
        int best = 0;
        vector<int> hs(heights);
        hs.push_back(0);                     // sentinel forces final flush
        for (int i = 0; i < (int)hs.size(); ++i) {
            int h = hs[i];
            while (!stk.empty() && hs[stk.back()] > h) {
                int top = stk.back();
                stk.pop_back();
                int left = stk.empty() ? -1 : stk.back();
                int width = i - left - 1;
                best = max(best, hs[top] * width);
            }
            stk.push_back(i);
        }
        return best;
    }
};
```

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();   // non-decreasing heights[stack]
        int best = 0;
        int[] hs = Arrays.copyOf(heights, heights.length + 1);  // sentinel 0 forces final flush
        for (int i = 0; i < hs.length; i++) {
            int h = hs[i];
            while (!stack.isEmpty() && hs[stack.peek()] > h) {
                int top = stack.pop();
                int left = stack.isEmpty() ? -1 : stack.peek();
                int width = i - left - 1;
                best = Math.max(best, hs[top] * width);
            }
            stack.push(i);
        }
        return best;
    }
}
```

```python
def largest_rectangle(heights):
    stack = []                           # non-decreasing heights[stack]
    best = 0
    heights = heights + [0]              # sentinel forces final flush
    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            top = stack.pop()
            left = stack[-1] if stack else -1
            width = i - left - 1
            best = max(best, heights[top] * width)
        stack.append(i)
    return best
```

## Walkthrough
The widget runs on heights `[2, 1, 5, 6, 2, 3]` with a virtual sentinel `0` at index 6:

1. **i = 0, 1.** Push `0` (height 2). At `i = 1` height 1 is smaller → pop `0`: width = `1`, area = **2**. Push `1`. Stack = `[1]`.
2. **i = 2, 3.** Heights 5 and 6 are strictly larger than the top → push both. Stack = `[1, 2, 3]`, bars 5 and 6 form the highlighted "window".
3. **i = 4 (height 2) — the big payoff.** Pop `3` (height 6): width = `4 - 2 - 1 = 1`, area = 6, best = 6. Pop `2` (height 5): width = `4 - 1 - 1 = 2`, area = **10**, best = 10 — watch the dashed green overlay span bars 2–3. Push `4`.
4. **i = 5 (3 > 2).** Push directly. Stack = `[1, 4, 5]`.
5. **End — sentinel at i = 6.** Pop `5` (h=3, w=1, area=3); pop `4` (h=2, w = `6 - 1 - 1 = 4`, area=8); pop `1` (h=1, w = `6 - (-1) - 1 = 6`, area=6). None beats 10, so **best = 10**.
