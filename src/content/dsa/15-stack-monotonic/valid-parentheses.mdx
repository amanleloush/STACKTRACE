## Problem
Given a string of `()[]{}`, decide if every opener is matched by a same-type closer in correct nesting order.

## Interview-ready explanation
I use a stack. I push every opening bracket; for a closing bracket, the stack must be non-empty and its top must be the matching opener, so I pop it, and otherwise I return false. At the end the string is valid only if the stack is empty. This works because the most recently opened bracket must be closed first, which is exactly last-in, first-out. Time is O(n) and space is O(n).

**One-liner:** Push openers; for each closer, check that it matches the top of the stack and pop. The string is valid if no mismatch occurs and the stack ends empty, in O(n) time and space.

## Intuition
A stack matches the LIFO grammar of nested brackets perfectly. Push every opener as you see it; when you see a closer, the most recently opened bracket must match it — peek the stack and pop. **Invariant**: at every point in the scan, the stack holds the prefix of openers that have not yet been closed, with the most recent on top. If the stack is ever empty when a closer arrives, or the top doesn't match, the string is invalid. If the stack is non-empty at the end, you have unmatched openers.

## Algorithm
Stack of openers with a closer→opener match table.

```cpp
class Solution {
public:
    bool isValid(string s) {
        unordered_map<char, char> match = {{')', '('}, {']', '['}, {'}', '{'}};
        vector<char> stk;
        for (char ch : s) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stk.push_back(ch);
            } else {
                if (stk.empty() || stk.back() != match[ch]) return false;
                stk.pop_back();
            }
        }
        return stk.empty();
    }
};
```

```java
class Solution {
    public boolean isValid(String s) {
        Map<Character, Character> match = Map.of(')', '(', ']', '[', '}', '{');
        Deque<Character> stack = new ArrayDeque<>();
        for (char ch : s.toCharArray()) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
            } else {
                if (stack.isEmpty() || !stack.peek().equals(match.get(ch))) return false;
                stack.pop();
            }
        }
        return stack.isEmpty();
    }
}
```

```python
def is_valid(s):
    match = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack[-1] != match[ch]:
                return False
            stack.pop()
    return not stack
```

## Walkthrough
Validate `"({[]})"`.

1. `(` — push. Stack: `[(]`.
2. `{` — push. Stack: `[(, {]`.
3. `[` — push. Stack: `[(, {, []`.
4. `]` — top `[` matches, pop. Stack: `[(, {]`.
5. `}` — top `{` matches, pop. Stack: `[(]`. Then `)` — top `(` matches, pop. Stack empty. Return `true`.
