## Problem
Add words to a dictionary, then search where `.` matches any single character. `search("b.d")` over `{bad, dad}` returns True.

## Interview-ready explanation
This is a trie with a DFS search. `addWord` inserts a word one character per trie node and marks the last node as a word end. `search` walks the trie character by character: on a normal letter it follows the one matching child, and on a `.` it tries every child recursively and returns True if any branch matches the rest of the query. A branch dies as soon as a needed child is missing, and at the end of the query the node must be marked as a word end. `addWord` is O(L); `search` is O(L) with no dots and O(26^w · L) in the worst case with `w` dots (LeetCode 211 allows at most 2), and space is O(total characters inserted).

**One-liner:** Store the words in a trie and search with DFS, following one child per letter and branching into every child on a `.`, so a search is O(L) normally and O(26^w · L) in the worst case.

## Intuition
A plain trie lookup follows exactly one child per character, so it can't handle `.`, where you must explore every child. Switch the search to **DFS**: at a regular character take the single matching child; at `.` recurse into all children. The branching factor is up to 26 at every dot, so a query with `w` wildcards costs O(26^w · L) in the worst case. In practice that's fine: LeetCode 211 allows at most 2 dots per query, and the trie prunes hard — any branch whose child is missing dies immediately.

```cpp
class WordDictionary {
    unordered_map<char, WordDictionary*> kids;
    bool end = false;

    bool searchFrom(const string& w, WordDictionary* node) {
        for (int i = 0; i < (int)w.size(); ++i) {
            char ch = w[i];
            if (ch == '.') {  // try every child for the rest of the word
                for (auto& kv : node->kids) {
                    if (searchFrom(w.substr(i + 1), kv.second)) return true;
                }
                return false;
            }
            auto it = node->kids.find(ch);
            if (it == node->kids.end()) return false;
            node = it->second;
        }
        return node->end;
    }

public:
    WordDictionary() {}

    void addWord(string word) {
        WordDictionary* node = this;
        for (char ch : word) {
            if (!node->kids.count(ch)) node->kids[ch] = new WordDictionary();
            node = node->kids[ch];
        }
        node->end = true;
    }

    bool search(string word) { return searchFrom(word, this); }
};
```

class WordDictionary {
    private final Map<Character, WordDictionary> kids = new HashMap<>();
    private boolean end = false;

    public WordDictionary() {}

    public void addWord(String word) {
        WordDictionary node = this;
        for (char ch : word.toCharArray()) {
            node = node.kids.computeIfAbsent(ch, k -> new WordDictionary());
        }
        node.end = true;
    }

    public boolean search(String word) { return searchFrom(word, this); }

    private boolean searchFrom(String w, WordDictionary node) {
        for (int i = 0; i < w.length(); i++) {
            char ch = w.charAt(i);
            if (ch == '.') {  // try every child for the rest of the word
                for (WordDictionary child : node.kids.values()) {
                    if (searchFrom(w.substring(i + 1), child)) return true;
                }
                return false;
            }
            node = node.kids.get(ch);
            if (node == null) return false;
        }
        return node.end;
    }
}

```python
class WordDictionary:
    def __init__(self):
        self.kids = {}
        self.end = False

    def addWord(self, w):
        node = self
        for ch in w:
            node = node.kids.setdefault(ch, WordDictionary())
        node.end = True

    def search(self, w, node=None):
        node = node or self
        for i, ch in enumerate(w):
            if ch == ".":
                return any(self.search(w[i+1:], c) for c in node.kids.values())
            node = node.kids.get(ch)
            if node is None: return False
        return node.end
```

## Walkthrough
Example: dictionary = `{car, cat, cab, dog, do}`. Query `search("c.t")`. The code above recurses; the steps below trace the same DFS as explicit `(node, index)` frames on a stack.

1. **Seed the stack.** Push `(root, i=0)`. Pop it; `ch = 'c'` is a regular char, and `root.kids` contains `c` → push `(c-node, 1)`.
2. **Fan out at the dot.** Pop `(c-node, 1)`; `ch = '.'` → push one frame per child of `c`. There's only one child (the `a` node shared by car/cat/cab) → push `(a-node, 2)`.
3. **Descend the second real char.** Pop `(a-node, 2)`; `ch = 't'`. `a.kids` has `{r, t, b}` — `t` is present → push `(t-node, 3)`.
4. **End of word — check end-flag.** Pop `(t-node, 3)`; `i == len(word)`. The `t` node is the terminal of the inserted word "cat", so `node.end == True` → **FOUND**, search returns True.
5. **End.** If "cat" weren't in the dictionary, that final frame would return False and DFS would backtrack to siblings via the stack (here there were no other live frames left).

## Pitfalls
- Slicing `w[i+1:]` is convenient but allocates — pass `i+1` as an index for tighter inner loops.
- Returning `True` as soon as you enter a wildcard branch, instead of recursing into the remaining suffix.
- Forgetting to check `node.end` at the end of the walk — `search("ba")` over `{bad}` must return False.
- Trying to store `.` as a child — `.` only appears in queries, never in stored words, so a 26-slot array still works.
- Confusing this with LC 10 (regex `.` and `*`) or LC 44 (glob `?` and `*`) — the `*` there means zero or more, so use DP, not a trie.
