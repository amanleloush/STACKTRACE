## Interview-ready explanation
A trie, or prefix tree, is a tree where each edge is one character, so the path from the root to any node spells a prefix, and nodes that complete a stored word carry an end-of-word flag. Words with a common prefix share one path. Insert, search and prefix check each walk at most L nodes for a string of length L, so they are O(L) no matter how many words are stored, and space is O(total characters) nodes. I reach for it when a problem asks many prefix queries, matches many words against one grid or text (Word Search II), needs wildcard lookup, or wants a maximum XOR pair (a binary trie over the bits of each number).

**One-liner:** A trie stores strings as shared character paths from a root with end-of-word flags, giving O(L) insert, search and prefix lookups that do not depend on how many words are stored.

## Trigger
**You see in the problem:** "prefix", "autocomplete / suggestions", "dictionary search with wildcards", "search many words in a grid", "longest common prefix", "XOR maximum pair" (binary trie).

**Reach for this pattern when:**
- Many queries on a **fixed set of words** with a **common prefix** flavor.
- Streaming inserts + prefix lookups — you'd otherwise rebuild a hash set per prefix.
- Multi-pattern matching against a grid/text — preprocess all patterns into a trie, walk once.
- Bitwise max-XOR queries — store integers as binary tries.

**Don't reach for it when:**
- One-off contains-check on a small set — a `set` is simpler and likely faster.
- Memory is tight and patterns are long — trie blows up to O(total chars) nodes.

## The mental model
A tree where each **edge** represents one character. The path from root to any node spells a prefix. Mark `end_of_word=True` at nodes that complete a stored word. Insert/lookup are **O(L)** per word of length L — independent of how many words are in the trie.

```cpp
struct TrieNode {
    unordered_map<char, TrieNode*> children;  // or TrieNode* children[26] for fixed alphabet
    bool end = false;
};

class Trie {
public:
    TrieNode* root = new TrieNode();

    void insert(const string& word) {
        TrieNode* node = root;
        for (char ch : word) {
            if (!node->children.count(ch)) node->children[ch] = new TrieNode();
            node = node->children[ch];
        }
        node->end = true;
    }

    bool search(const string& word) {
        TrieNode* node = walk(word);
        return node != nullptr && node->end;
    }

    bool startsWith(const string& prefix) { return walk(prefix) != nullptr; }

private:
    TrieNode* walk(const string& s) {
        TrieNode* node = root;
        for (char ch : s) {
            if (!node->children.count(ch)) return nullptr;
            node = node->children[ch];
        }
        return node;
    }
};

// Wildcard search ('.' matches any char) — DFS at each '.'
bool dfs(TrieNode* node, const string& word, int i) {
    if (i == (int)word.size()) return node->end;
    char ch = word[i];
    if (ch == '.') {
        for (auto& kv : node->children) {
            if (dfs(kv.second, word, i + 1)) return true;
        }
        return false;
    }
    if (!node->children.count(ch)) return false;
    return dfs(node->children[ch], word, i + 1);
}

bool searchWild(TrieNode* root, const string& word) { return dfs(root, word, 0); }
```

```java
class TrieNode {
    Map<Character, TrieNode> children = new HashMap<>();  // or new TrieNode[26] for fixed alphabet
    boolean end = false;
}

class Trie {
    TrieNode root = new TrieNode();

    void insert(String word) {
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            node = node.children.computeIfAbsent(ch, k -> new TrieNode());
        }
        node.end = true;
    }

    boolean search(String word) {
        TrieNode node = walk(word);
        return node != null && node.end;
    }

    boolean startsWith(String prefix) { return walk(prefix) != null; }

    private TrieNode walk(String s) {
        TrieNode node = root;
        for (char ch : s.toCharArray()) {
            node = node.children.get(ch);
            if (node == null) return null;
        }
        return node;
    }
}

class Solution {
    // Wildcard search ('.' matches any char) — DFS at each '.'
    static boolean searchWild(TrieNode root, String word) { return dfs(root, word, 0); }

    private static boolean dfs(TrieNode node, String word, int i) {
        if (i == word.length()) return node.end;
        char ch = word.charAt(i);
        if (ch == '.') {
            for (TrieNode c : node.children.values()) {
                if (dfs(c, word, i + 1)) return true;
            }
            return false;
        }
        TrieNode next = node.children.get(ch);
        if (next == null) return false;
        return dfs(next, word, i + 1);
    }
}
```

```python
class TrieNode:
    __slots__ = ('children', 'end')
    def __init__(self):
        self.children = {}     # or [None] * 26 for fixed alphabet
        self.end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.end = True

    def search(self, word):
        node = self._walk(word)
        return node is not None and node.end

    def starts_with(self, prefix):
        return self._walk(prefix) is not None

    def _walk(self, s):
        node = self.root
        for ch in s:
            if ch not in node.children: return None
            node = node.children[ch]
        return node

# Wildcard search ('.' matches any char) — DFS at each '.'
def search_wild(root, word):
    def dfs(node, i):
        if i == len(word): return node.end
        ch = word[i]
        if ch == '.':
            return any(dfs(c, i+1) for c in node.children.values())
        if ch not in node.children: return False
        return dfs(node.children[ch], i+1)
    return dfs(root, 0)
```

## Complexity
- Insert / search / starts-with: **O(L)** where L = word length.
- Space: **O(total_chars)** nodes; with a fixed `[None] * Σ` array per node that is O(Σ × total_chars) memory, with a dict only used branches cost anything.
- Wildcard search: O(Σ^w × L) worst for `w` wildcards (bounded by the number of trie nodes); far less in practice because missing children prune.

## Variants in this pattern
1. **Plain trie** — insert/search/starts-with.
2. **Dictionary with wildcards** — `.` matches any character; DFS at wildcards.
3. **Multi-pattern grid search** — Boggle / Word Search II: trie of words + DFS in grid.
4. **Autocomplete / top-K** — store frequency at end-nodes, collect descendants of a prefix.
5. **Binary trie / 0-1 trie** — XOR maximum / minimum pair; insert ints bit by bit from MSB.
6. **Compressed trie (radix tree)** — collapse single-child chains, save memory.

## Common bugs / pitfalls
- **Forgetting `end=True`** — after inserting only "applesauce", `starts_with("apple")` is True but `search("apple")` must be False; only the end flag tells them apart.
- **Wildcard search exploring everything** — prune as soon as `ch not in children` (when non-wildcard); only branch on `.`.
- **Reusing root for many tests** without reset — keep tries immutable post-build, or rebuild per test case.
- **Word Search II — not removing found words** from the trie → time-out via repeated re-discovery.
- **Memory blowup** with `[None] * 26` at every node when alphabet is sparse — use a dict.
- **Binary trie depth**: fix to 31 or 32 bits, MSB first, or you'll compare numbers of different bit-lengths incorrectly.
