## Problem
Given a grid of letters and a list of words, return every word that can be spelled by a path of adjacent (4-dir) cells without revisiting any cell.

## Interview-ready explanation
This is the trie + backtracking pattern. I put all the words into one trie, then start a DFS from every cell, carrying the trie node that matches the path so far; if the next cell's letter isn't a child of that node, that path stops immediately. When I reach a node that ends a word, I record the word and clear the mark so it is never reported twice. During a path I mark cells as visited and restore them on the way back, and I delete trie nodes that become empty so later searches skip them. Time is O(R·C·4·3^(L−1)), usually written O(R·C·4^L), where L is the longest word length; space is O(total characters in the words) for the trie plus O(L) recursion depth.

**One-liner:** Build one trie of all the words and run a backtracking DFS from every cell that walks the grid and the trie together, pruning a path as soon as it isn't a prefix of any remaining word.

## Intuition
Running Word Search I once per word is O(W · R · C · 4^L). Instead, **build a trie from all words** and run a single DFS from every cell, carrying the current trie node alongside the path. At each step you check whether the current letter is a child of the node — if not, prune instantly. When you hit `node.end`, record the word and clear the end-flag (or null the leaf) to avoid duplicates. Add one more optimization: when a trie node has no children left, splice it out so future paths bail earlier. This is the difference between "passes LC tests" and "passes in 50 ms."

## Algorithm
```python
def findWords(board, words):
    root = {}
    for w in words:                  # build trie
        node = root
        for ch in w: node = node.setdefault(ch, {})
        node["$"] = w                # word at terminal

    R, C, out = len(board), len(board[0]), []

    def dfs(r, c, node):
        ch = board[r][c]
        nxt = node.get(ch)
        if not nxt: return
        if "$" in nxt:
            out.append(nxt.pop("$"))  # dedupe
        board[r][c] = "#"
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r+dr, c+dc
            if 0 <= nr < R and 0 <= nc < C and board[nr][nc] != "#":
                dfs(nr, nc, nxt)
        board[r][c] = ch
        if not nxt: node.pop(ch)     # prune dead branch

    for r in range(R):
        for c in range(C):
            dfs(r, c, root)
    return out
```

## Walkthrough
Example: grid `[["o","a","t"], ["e","a","h"]]`, words `["oath", "oat", "eat"]`.

1. **Build trie + seed start cells.** Trie root has children `o` and `e`. DFS frames are pushed for every cell `(r,c)` and tried in row-major order with `cursor = root`.
2. **Start at (0,0)='o' — finds "oat".** Trie has child `o`, descend. Spawn DFS into (0,1)='a' (cursor walks `o → a`). From (0,1), (1,1)='a' has no `a` child below → pruned; (0,2)='t' descends to `t`, which is the end of "oat" → record **"oat"**.
3. **Continue from "oat" — finds "oath".** The `t` node still has child `h`. From (0,2) spawn into (1,2)='h' → descend to `h` (end-flag) → record **"oath"**.
4. **Other starts get pruned fast.** Starts at (0,1)='a', (0,2)='t', (1,1)='a', (1,2)='h' all fail the very first child lookup under root (root only has `o` and `e`) → prune immediately. **This is where the trie pays off.**
5. **Start at (1,0)='e' — "eat" is not on this grid.** Descend root → `e` node. Spawn into neighbours; (0,0)='o' isn't an `a` child → prune; (1,1)='a' descends `e → a`. From (1,1)='a', neighbour (0,1)='a' has no `a` child of `a` → prune. (1,1)'s other neighbours are (1,0) (already on the path) and (1,2)='h', which is not the `t` child → prune. No 't' touches that 'a', so **"eat" is not found**. Final result: **{oat, oath}**. (The widget lists "eat" in the trie, but this grid cannot spell it.)

## Complexity

time **O(R·C·4^L)** · space **O(Σ L)**

## Pitfalls
- Not deduping found words — pop `$` from the node, or use a set.
- Forgetting to restore `board[r][c]` after recursion — corrupts later starting cells.
- Iterating all words inside DFS instead of indexing them in the trie — kills the optimization.
- Trie node pruning is what makes it fast; skip it and large inputs TLE.
- Diagonal moves are not allowed in LC 79/212 — only 4-direction.
