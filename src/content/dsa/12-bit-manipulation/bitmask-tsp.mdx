## Problem
Given an `n×n` distance matrix (`n ≤ 20`), find the shortest tour visiting every city exactly once and returning to the start.

## Interview-ready explanation
This is bitmask DP, known as the Held–Karp algorithm. The state `dp[mask][u]` is the cheapest way to start at city 0, visit exactly the cities in `mask`, and end at city `u`. I process masks in increasing order and extend each reachable state to every unvisited city `v`: `dp[mask | (1 << v)][v] = min(itself, dp[mask][u] + dist[u][v])`. The answer is the minimum over `u` of `dp[full][u] + dist[u][0]`, which adds the trip back home. There are 2^n · n states with n transitions each, so time is O(2^n · n²) and space is O(2^n · n), versus O(n!) for trying every order.

**One-liner:** Held–Karp: DP over (visited-set bitmask, current city), extending the path by one unvisited city at a time, which solves TSP in O(2^n · n²) instead of O(n!).

## Intuition
The state is **(set of visited cities, current city)** — once you know which cities you've visited and where you are, the future is independent of the past. Encode the visited set as a bitmask: bit `i` set means city `i` is done. There are `2^n · n` states; each tries up to `n` next cities. Total `O(2^n · n²)` time and `O(2^n · n)` space. For `n = 20` that's roughly 4·10^8 — tight but doable in C++/Java (too slow in pure Python). The shift from "permutation search" (n! ≈ 2.4·10^18 at n=20) to "subset DP" (~ 4·10^8) is what makes the problem tractable.

```cpp
int tsp(const vector<vector<int>>& dist) {
    int n = (int)dist.size();
    const int INF = 1000000000;                     // larger than any tour
    vector<vector<int>> dp(1 << n, vector<int>(n, INF));
    dp[1][0] = 0;                                   // start at city 0
    for (int mask = 0; mask < (1 << n); ++mask) {
        for (int u = 0; u < n; ++u) {
            if (dp[mask][u] == INF || !((mask >> u) & 1)) continue;
            for (int v = 0; v < n; ++v) {
                if ((mask >> v) & 1) continue;      // v already visited
                int nmask = mask | (1 << v);
                dp[nmask][v] = min(dp[nmask][v], dp[mask][u] + dist[u][v]);
            }
        }
    }
    if (n == 1) return 0;                           // single city: empty tour
    int full = (1 << n) - 1, best = INF;
    for (int u = 1; u < n; ++u) best = min(best, dp[full][u] + dist[u][0]);
    return best;
}
```

```java
class Solution {
    static int tsp(int[][] dist) {
        int n = dist.length;
        final int INF = 1_000_000_000;                  // larger than any tour
        int[][] dp = new int[1 << n][n];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[1][0] = 0;                                   // start at city 0
        for (int mask = 0; mask < (1 << n); mask++) {
            for (int u = 0; u < n; u++) {
                if (dp[mask][u] == INF || ((mask >> u) & 1) == 0) continue;
                for (int v = 0; v < n; v++) {
                    if (((mask >> v) & 1) == 1) continue;   // v already visited
                    int nmask = mask | (1 << v);
                    dp[nmask][v] = Math.min(dp[nmask][v], dp[mask][u] + dist[u][v]);
                }
            }
        }
        if (n == 1) return 0;                           // single city: empty tour
        int full = (1 << n) - 1, best = INF;
        for (int u = 1; u < n; u++) best = Math.min(best, dp[full][u] + dist[u][0]);
        return best;
    }
}
```

```python
def tsp(dist):
    n = len(dist)
    INF = float("inf")
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0                                    # start at city 0
    for mask in range(1 << n):
        for u in range(n):
            if dp[mask][u] == INF or not (mask >> u) & 1: continue
            for v in range(n):
                if (mask >> v) & 1: continue        # v already visited
                nmask = mask | (1 << v)
                dp[nmask][v] = min(dp[nmask][v], dp[mask][u] + dist[u][v])
    if n == 1: return 0                             # single city: empty tour
    full = (1 << n) - 1
    return min(dp[full][u] + dist[u][0] for u in range(1, n))
```

## Walkthrough
Example: 4 cities with symmetric distances `[[0,10,15,20], [10,0,35,25], [15,35,0,30], [20,25,30,0]]`. Start at city 0.

1. **Base state.** `dp[mask=0001][i=0] = 0` — only city 0 visited, currently sitting there.
2. **Expand by popcount = 1.** From `(0001, 0)` relax three transitions: `dp[0011][1] = 0+10 = 10`, `dp[0101][2] = 0+15 = 15`, `dp[1001][3] = 0+20 = 20`.
3. **Expand by popcount = 2.** E.g. from `(0011, 1)`: relax to `dp[0111][2] = 10+35 = 45`, `dp[1011][3] = 10+25 = 35`. From `(0101, 2)`: `dp[0111][1] = 15+35 = 50`, `dp[1101][3] = 15+30 = 45`. And so on for `(1001, 3)`.
4. **Expand by popcount = 3.** Each popcount-3 state has exactly one unvisited city left, so it relaxes one transition into the full mask. After this layer, `dp[FULL=1111][i]` is filled for `i ∈ {1, 2, 3}`: `dp[1111][1] = 70` (path `0→2→3→1` = 15+30+25), `dp[1111][2] = 65` (`0→1→3→2` = 10+25+30), `dp[1111][3] = 75` (`0→1→2→3` or `0→2→1→3`).
5. **Close the tour.** Take `min over i of dp[1111][i] + dist[i][0]`: candidate end-cities give `dp[1111][1]+10 = 80`, `dp[1111][2]+15 = 80`, `dp[1111][3]+20 = 95`. **Best tour cost = 80** (e.g. `0→2→3→1→0`, or the same cycle reversed).
