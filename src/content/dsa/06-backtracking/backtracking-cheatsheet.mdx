## Interview-ready explanation
Backtracking is a DFS over a tree of choices. I build a candidate step by step: at each step I make a choice, recurse to make the remaining choices, then undo that choice so the next option starts from a clean state. When the partial candidate breaks a constraint, I prune that branch without exploring it. When it's complete, I save a copy of it. The running time is roughly the number of nodes in the choice tree times the work per node: O(n · 2ⁿ) for subsets and O(n · n!) for permutations. Extra space is O(depth) for the recursion stack, not counting the output.

**One-liner:** DFS over a choice tree with choose → recurse → undo, pruning invalid partial answers early; cost is the size of the explored tree, e.g. O(n · 2ⁿ) for subsets.

## Trigger
**You see in the problem:** "all subsets / all permutations / all combinations", "N-queens", "Sudoku", "generate all valid X", "word search in grid", "find a path that satisfies …".

**Reach for this pattern when:**
- You must **enumerate** every solution (not just one, not just count).
- The search forms a **tree of choices**, each path possibly a solution.
- Constraints let you **prune** invalid branches early — that's what makes it tractable.
- Constraints are small (n ≤ ~20, often ≤ 10).

**Don't reach for it when:**
- You only need the **count** or **the best** — DP/greedy is usually faster.
- The branching factor × depth × constraints can't be tamed by pruning — exponential will time out.

## The mental model
DFS with explicit **make-choice / recurse / un-make-choice**. The recursion tree's leaves are candidate solutions. At each node, pick a choice, recurse, then **undo** so the same path slot can try the next choice. Pruning happens by checking constraints *before* recursing.

```cpp
// Generic backtracking template; the problem supplies these three hooks
bool isSolution(const vector<int>& path);
bool isValid(const vector<int>& path, int c);
vector<int> nextChoices(const vector<int>& path, int c);

void backtrack(vector<int>& path, const vector<int>& choices, vector<vector<int>>& result) {
    if (isSolution(path)) {
        result.push_back(path);  // snapshot — path is mutated
        return;
    }
    for (int c : choices) {
        if (!isValid(path, c)) continue;
        path.push_back(c);  // make choice
        backtrack(path, nextChoices(path, c), result);
        path.pop_back();  // undo choice
    }
}

class Solution {
public:
    // Subsets — include/exclude
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> res;
        vector<int> path;
        function<void(int)> go = [&](int i) {
            if (i == (int)nums.size()) {
                res.push_back(path);
                return;
            }
            path.push_back(nums[i]);  // take
            go(i + 1);
            path.pop_back();
            go(i + 1);  // skip
        };
        go(0);
        return res;
    }

    // Permutations — used[] set
    vector<vector<int>> permute(vector<int>& nums) {
        vector<vector<int>> res;
        vector<int> path;
        vector<bool> used(nums.size(), false);
        function<void()> go = [&]() {
            if (path.size() == nums.size()) {
                res.push_back(path);
                return;
            }
            for (size_t i = 0; i < nums.size(); ++i) {
                if (used[i]) continue;
                used[i] = true;
                path.push_back(nums[i]);
                go();
                path.pop_back();
                used[i] = false;
            }
        };
        go();
        return res;
    }
};
```

```java
// Generic backtracking template; a subclass supplies the three hooks
abstract class Backtracker {
    abstract boolean isSolution(List<Integer> path);
    abstract boolean isValid(List<Integer> path, int c);
    abstract List<Integer> nextChoices(List<Integer> path, int c);

    void backtrack(List<Integer> path, List<Integer> choices, List<List<Integer>> result) {
        if (isSolution(path)) {
            result.add(new ArrayList<>(path));  // snapshot — list is mutated
            return;
        }
        for (int c : choices) {
            if (!isValid(path, c)) continue;
            path.add(c);  // make choice
            backtrack(path, nextChoices(path, c), result);
            path.remove(path.size() - 1);  // undo choice
        }
    }
}

class Solution {
    // Subsets — include/exclude
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        goSubsets(nums, 0, new ArrayList<>(), res);
        return res;
    }

    private void goSubsets(int[] nums, int i, List<Integer> path, List<List<Integer>> res) {
        if (i == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        path.add(nums[i]);  // take
        goSubsets(nums, i + 1, path, res);
        path.remove(path.size() - 1);
        goSubsets(nums, i + 1, path, res);  // skip
    }

    // Permutations — used[] set
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        goPermute(nums, new ArrayList<>(), new boolean[nums.length], res);
        return res;
    }

    private void goPermute(int[] nums, List<Integer> path, boolean[] used,
                           List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.add(nums[i]);
            goPermute(nums, path, used, res);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

```python
# Generic backtracking template
def backtrack(path, choices, result):
    if is_solution(path):
        result.append(path[:])           # snapshot — list is mutated
        return
    for c in choices:
        if not is_valid(path, c): continue
        path.append(c)                   # make choice
        backtrack(path, next_choices(path, c), result)
        path.pop()                       # undo choice

# Subsets — include/exclude
def subsets(nums):
    res, path = [], []
    def go(i):
        if i == len(nums):
            res.append(path[:]); return
        path.append(nums[i]); go(i + 1); path.pop()   # take
        go(i + 1)                                      # skip
    go(0)
    return res

# Permutations — used[] set
def permute(nums):
    res, path, used = [], [], [False] * len(nums)
    def go():
        if len(path) == len(nums):
            res.append(path[:]); return
        for i in range(len(nums)):
            if used[i]: continue
            used[i] = True;  path.append(nums[i])
            go()
            path.pop();      used[i] = False
    go()
    return res
```

## Complexity
- Time: **(nodes in the choice tree) × (work per node)**, bounded by O(branches^depth) — e.g., O(n · n!) for permutations, O(2^n · n) for subsets.
- Space: **O(depth)** recursion + O(output) for results.

## Variants in this pattern
1. **Subsets / power set** — include-or-skip at each index.
2. **Permutations** — `used[]` flag or in-place swap to avoid repeats.
3. **Combinations** — start index, pick k of n.
4. **Grid search** — DFS with visited cell marking + un-marking.
5. **Constraint satisfaction** — N-queens, sudoku; prune by row/col/diag/box sets.
6. **String construction** — generate valid parentheses, restore IPs.

## Common bugs / pitfalls
- **Appending `path` instead of `path[:]`** — same list reference; all results end up identical (usually empty by the end).
- **Forgetting to undo** the choice — `path.pop()` / `used[i] = False`. Without it, the sibling branches see stale state.
- **Duplicate results with duplicate input** — sort first, then skip `nums[i] == nums[i-1]` at the same recursion level (for subsets/combinations: when `i > start`; for permutations: when `nums[i-1]` is not currently used).
- **Mutating the grid as visited** without restoring — a failed branch leaves its cells blocked, so later branches miss valid paths. Always unmark on the way out.
- **Wrong base case** — recursing past the last index, indexing OOB.
- **Pruning too late** — check `is_valid(path, c)` *before* appending, not inside the recursive call.
