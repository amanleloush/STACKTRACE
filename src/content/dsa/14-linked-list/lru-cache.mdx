## Problem
Design a cache supporting `get(key)` and `put(key, value)` in O(1), evicting the least-recently-used entry when capacity is exceeded.

## Interview-ready explanation
An LRU cache needs O(1) lookup and O(1) reordering by recency, so I combine a hash map from key to node with a doubly linked list ordered from most to least recently used, with dummy head and tail nodes. `get` looks up the node, moves it to the front, and returns its value (or -1 if missing). `put` updates and moves an existing node; for a new key, if the cache is full it first evicts the node just before the tail and deletes its key from the map, then inserts the new node at the front. Every operation is O(1) time, and space is O(capacity).

**One-liner:** A hash map from key to node plus a doubly linked list in recency order: move a node to the front on every access and evict from the tail, all in O(1).

## Intuition
You need two things in O(1): **lookup by key** (hash map) and **ordering by recency with constant-time removal from the middle** (doubly-linked list). Keep a hash map `key → DLL node`. The DLL has a dummy head and dummy tail; the node next to head is most-recently-used, the node before tail is least-recently-used. **Invariant**: every key in the map points to a node currently in the DLL, and DLL order is exactly recency order from MRU (front) to LRU (back). Every operation touches one map slot and a constant number of DLL pointer updates.

## Algorithm
HashMap + doubly-linked list with sentinel head/tail.

```cpp
class LRUCache {
    struct Node {
        int k, v;
        Node* prev = nullptr;
        Node* nxt = nullptr;
        Node(int k, int v) : k(k), v(v) {}
    };
    int cap;
    unordered_map<int, Node*> m;
    Node* head = new Node(0, 0);         // sentinels
    Node* tail = new Node(0, 0);

    void remove(Node* n) {
        n->prev->nxt = n->nxt;
        n->nxt->prev = n->prev;
    }

    void addFront(Node* n) {
        n->prev = head;
        n->nxt = head->nxt;
        head->nxt->prev = n;
        head->nxt = n;
    }

public:
    LRUCache(int capacity) : cap(capacity) {
        head->nxt = tail;
        tail->prev = head;
    }

    int get(int key) {
        auto it = m.find(key);
        if (it == m.end()) return -1;
        Node* n = it->second;
        remove(n); addFront(n);
        return n->v;
    }

    void put(int key, int value) {
        auto it = m.find(key);
        if (it != m.end()) {
            Node* n = it->second; n->v = value;
            remove(n); addFront(n);
            return;
        }
        if ((int)m.size() == cap) {
            Node* lru = tail->prev;
            remove(lru); m.erase(lru->k); delete lru;
        }
        Node* n = new Node(key, value); m[key] = n; addFront(n);
    }
};
```

```java
class LRUCache {
    private static class Node {
        int k, v;
        Node prev, nxt;
        Node(int k, int v) { this.k = k; this.v = v; }
    }

    private final int cap;
    private final Map<Integer, Node> m = new HashMap<>();
    private final Node head = new Node(0, 0);  // sentinels
    private final Node tail = new Node(0, 0);

    public LRUCache(int capacity) {
        cap = capacity;
        head.nxt = tail;
        tail.prev = head;
    }

    private void remove(Node n) {
        n.prev.nxt = n.nxt;
        n.nxt.prev = n.prev;
    }

    private void addFront(Node n) {
        n.prev = head;
        n.nxt = head.nxt;
        head.nxt.prev = n;
        head.nxt = n;
    }

    public int get(int key) {
        Node n = m.get(key);
        if (n == null) return -1;
        remove(n); addFront(n);
        return n.v;
    }

    public void put(int key, int value) {
        Node n = m.get(key);
        if (n != null) {
            n.v = value;
            remove(n); addFront(n);
            return;
        }
        if (m.size() == cap) {
            Node lru = tail.prev;
            remove(lru); m.remove(lru.k);
        }
        n = new Node(key, value); m.put(key, n); addFront(n);
    }
}
```

```python
class Node:
    __slots__ = ("k", "v", "prev", "nxt")
    def __init__(self, k, v):
        self.k, self.v = k, v
        self.prev = self.nxt = None

class LRUCache:
    def __init__(self, cap):
        self.cap = cap
        self.m = {}
        self.head = Node(0, 0)           # sentinels
        self.tail = Node(0, 0)
        self.head.nxt = self.tail
        self.tail.prev = self.head

    def _remove(self, n):
        n.prev.nxt, n.nxt.prev = n.nxt, n.prev

    def _add_front(self, n):
        n.prev = self.head
        n.nxt = self.head.nxt
        self.head.nxt.prev = n
        self.head.nxt = n

    def get(self, k):
        if k not in self.m: return -1
        n = self.m[k]
        self._remove(n); self._add_front(n)
        return n.v

    def put(self, k, v):
        if k in self.m:
            n = self.m[k]; n.v = v
            self._remove(n); self._add_front(n)
            return
        if len(self.m) == self.cap:
            lru = self.tail.prev
            self._remove(lru); del self.m[lru.k]
        n = Node(k, v); self.m[k] = n; self._add_front(n)
```

## Walkthrough
The widget runs 8 operations on a cache with `cap = 2`: `put(1,1) · put(2,2) · get(1) · put(3,3) · get(2) · put(4,4) · get(1) · get(3)`.

1. **Fill the cache.** `put(1,1)` then `put(2,2)` insert at head. DLL becomes `head → (2=2) → (1=1) → tail`. Most-recent on the left, LRU on the right.
2. **`get(1)` is a hit.** Move node `1` to head → `(1=1) → (2=2)`. Readout shows `returned: 1`. The whole point of LRU: a touched key is no longer near eviction.
3. **`put(3,3)` triggers eviction.** The cache is full, so the LRU node at the tail is evicted (the widget inserts first and then pops the tail; the code above evicts first — same result). The tail is `(2=2)` because we just demoted it in step 2 → evict it. DLL = `(3=3) → (1=1)`.
4. **`get(2)` misses.** Not in the DLL anymore → `returned: -1`. `put(4,4)` then inserts at head and evicts the new tail `(1=1)` → DLL = `(4=4) → (3=3)`.
5. **End — `get(1)` misses, `get(3)` hits.** `get(1)` returns `-1`. `get(3)` finds the node, moves it to head → final DLL `(3=3) → (4=4)`. Every operation touched one map entry and a constant number of DLL pointers.
