## Problem
Given a string `s`, return the length of the longest substring with **all distinct characters**.

## Interview-ready explanation

This is a variable-size sliding window with a last-seen map. I keep a window from l to r that has no repeated characters, and a hash map from each character to the last index where I saw it. For each new character at r, if its last index is inside the window (at least l), I jump l to one past that index, which removes the earlier copy in one move. Then I record r as its last index and update the best length, r - l + 1. Both pointers only move forward, so it is O(n) time and O(min(n, alphabet size)) space.

**One-liner:** Grow the window to the right and, on a repeat inside it, jump the left edge past the character's last-seen index; O(n) time.

## Intuition
Maintain a window `[l, r]` that always contains distinct characters. Extend by adding `s[r]`. If `s[r]` is already inside (we've seen it at index `last`), the leftmost we can keep `l` is `last + 1`. Use a hash map `last_seen` so this lookup is O(1). The invariant: `s[l..r]` is always a substring with no repeats, and `r - l + 1` is its length. Each index is added once and `l` only moves right, so the sweep is O(n).

## Algorithm
1. `last_seen = {}`, `l = 0`, `best = 0`.
2. For `r` in 0..n-1:
   - If `s[r]` is in `last_seen` and `last_seen[s[r]] >= l`, jump `l = last_seen[s[r]] + 1`.
   - Update `last_seen[s[r]] = r`.
   - `best = max(best, r - l + 1)`.
3. Return `best`.

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> last;
        int l = 0, best = 0;
        for (int r = 0; r < (int)s.size(); ++r) {
            char ch = s[r];
            auto it = last.find(ch);
            if (it != last.end() && it->second >= l) {
                l = it->second + 1;
            }
            last[ch] = r;
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> last = new HashMap<>();
        int l = 0, best = 0;
        for (int r = 0; r < s.length(); r++) {
            char ch = s.charAt(r);
            Integer prev = last.get(ch);
            if (prev != null && prev >= l) {
                l = prev + 1;
            }
            last.put(ch, r);
            best = Math.max(best, r - l + 1);
        }
        return best;
    }
}

## Walkthrough
On `s = "abcabcbb"`:

- `r=0, 'a'`: window `[0,0]="a"`, `best=1`.
- `r=1, 'b'`: window `[0,1]="ab"`, `best=2`.
- `r=2, 'c'`: window `[0,2]="abc"`, `best=3`.
- `r=3, 'a'`: `'a'` last seen at 0, jump `l=1`. Window `[1,3]="bca"`, `best=3`.
- `r=4, 'b'`: `'b'` last seen at 1, jump `l=2`. Window `[2,4]="cab"`.
- `r=6, 'b'`: jump again. By `r=7`, the best is still 3.

Return `3`.

## Complexity

- time **O(n)**
- space **O(min(n, σ))** where σ is the alphabet size

## Pitfalls
- **Forgetting the `last_seen[ch] >= l` check.** A character may have been seen *before* the current window. Without the check, `l` jumps *backwards* to that stale index and the window suddenly contains repeats (on `"abba"` you would return 3 instead of 2).
- Using `set` and removing characters one-by-one as `l` advances — correct but more code; the "jump `l`" trick is cleaner.
- Updating `best` before the `last_seen` update vs after — both work because the window is valid by the time you measure it; pick a convention.
- For "at most K distinct" extend the same idea — counter map plus a `distinct` count.
