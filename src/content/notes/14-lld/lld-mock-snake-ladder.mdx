## Definition (interview-ready)

This mock asks you to build a Snake and Ladder game that is easy to test and cheap to extend. The core entities are `Board` (its size plus one jump map from start cell to end cell, because a snake and a ladder are the same thing in opposite directions), `Dice`, `Player`, `Game` (a turn deque, player positions and the winner) and a `TurnResult` record. `Dice` is an interface injected into `Game`, so tests use scripted rolls and demos use a seeded `Random`. A Builder validates the board once, at construction: snakes go down, ladders go up, no jump on the first or last cell, and no chained jumps. The usual extensions plug in without editing `Game`: a `MultiDice` composite for several dice, and an `EndRule` strategy for exact roll, overshoot wins or bounce back.

**One-liner:** A Game that takes an injected Dice, a validated immutable Board with one jump map for snakes and ladders, and a turn deque, with Strategy for the end rule and Composite for multiple dice.

## The problem

> **Build a Snake and Ladder game.**
>
> - The board has `N` cells numbered 1 to `N` (default 100). The board size must be configurable.
> - The board has some **snakes** (a head cell and a lower tail cell) and **ladders** (a bottom cell and a higher top cell). Landing on a snake's head moves you down to its tail; landing on a ladder's bottom moves you up to its top.
> - Two or more **players** take **turns** in a fixed order. Every player starts off the board.
> - On a turn, a player rolls a **six-sided die** and moves forward by the rolled value, then follows any snake or ladder on the cell they land on.
> - The first player to reach exactly cell `N` **wins**, and the game ends.
> - The dice must be **replaceable for testing**: tests should be able to run a game with a predetermined sequence of rolls, and a "random" game should be reproducible.
> - Show it working: play a full game from `main` and print each move (or a summary), and include tests.
>
> **Extensions (the interviewer will ask for one or two of these around minute 40–45 — design so they are cheap):**
>
> 1. Play with **more than one die** (for example two dice, moving by the sum).
> 2. Make the end-of-board rule configurable: **exact roll to win** (overshoot means you stay put), **overshoot wins**, or **bounce back** from the last cell by the excess.
> 3. Reject **invalid boards** (a snake that goes up, a jump starting on the last cell, two jumps on one cell, a snake tail sitting on a ladder bottom).

## Hints

Open one at a time.

<QA q="Hint 1 — Where does randomness live, and how do I test a dice game?" level="easy">

Make randomness a **dependency**, not a detail. Declare `interface Dice { int roll(); }` and pass a `Dice` into the game's constructor. Then write two implementations: one wrapping `java.util.Random` created **with a seed** (same seed, same rolls — that's a documented guarantee of `Random`), and one that returns a **fixed sequence** you supply (`new FixedDice(3, 5, 6)`). Now every test can script exactly what happens.

This is plain Dependency Inversion — see [SOLID Principles](/learn/notes/solid-principles/).

</QA>

<QA q="Hint 2 — How should I model snakes and ladders?" level="medium">

A snake and a ladder are the **same thing with opposite direction**: "if you land on cell X, go to cell Y". Store them all in one `Map` from start cell to end cell inside a `Board`. Moving is then two steps: compute the landing cell, then `jumps.getOrDefault(landed, landed)`. Whether it was a snake or ladder is just "did we go down or up".

Validate in a **builder**: snake must go down, ladder up; no jump starts on cell 1 or the last cell; one jump per start cell; and no jump **ends** on another jump's start (that would create chains or loops). Once built, the board is immutable.

</QA>

<QA q="Hint 3 — How do the extensions plug in without touching the game loop?" level="hard">

- **Multiple dice:** a `MultiDice` that holds a list of `Dice` and **is itself a `Dice`** whose `roll()` returns the sum. The game never knows. That's the Composite idea (see [Structural Patterns](/learn/notes/structural-patterns/)).
- **End rule:** an `EndRule` strategy with one method, `int advance(int from, int roll, int size)`, returning the cell reached before snakes and ladders. Exact-roll returns `from` on overshoot, overshoot-wins caps at `size`, bounce-back reflects. An `enum` implementing the interface is a neat way to ship the three rules. See Strategy in [Behavioral Patterns](/learn/notes/behavioral-patterns/).
- **Turn order:** an `ArrayDeque` of players — poll the head, play, add to the tail.
- `playTurn()` should **return a value** (`TurnResult`: player, roll, from, landed, to, jump, won) so `main` prints and tests assert — the domain never calls `System.out`.

</QA>

<QA q="Reference design — clarifying assumptions, classes and patterns" level="medium">

**Assumptions stated up front** (what a good candidate writes in the first 5 minutes):

- Players start at position 0 ("off the board"); a roll of 3 puts you on cell 3.
- One jump per cell; no chained jumps; no jump on cell 1 or the last cell (a ladder **ending** on the last cell is allowed and wins).
- Default end rule: **exact roll to win**. Game ends at the **first** winner.
- In-memory, single game per `Game` object, driven from `main`.

**Classes:**

```text
            +-------------------+
            |   «interface»     |
            |       Dice        |  roll(), maxRoll()
            +-------------------+
              ^       ^       ^
     RandomDice   FixedDice   MultiDice --holds--> List<Dice>    (Composite)
     (seeded)     (scripted)

  +-------------------+        +---------------------------+
  |      Board        |        |  «interface» EndRule      |  advance(from, roll, size)
  | size              |        +---------------------------+
  | jumps: Map<Int,Int>|          ^  enum EndRules:            (Strategy)
  | destination(cell) |          |  EXACT_ROLL, OVERSHOOT_WINS, BOUNCE_BACK
  | Builder (validates)|
  +-------------------+
            ^
            |  uses                    Player (record: name)
  +-----------------------------+      TurnResult (record: player, roll,
  |           Game              |        from, landed, to, jump, won)
  | board, dice, endRule        |
  | turnOrder: Deque<Player>    |
  | positions: Map<Player,Int>  |
  | playTurn(): TurnResult      |
  | playToEnd(maxTurns): Player |
  +-----------------------------+
```

**Why these choices:**

| Decision | Reason |
|---|---|
| `Dice` interface injected into `Game` | Tests script rolls; demos stay reproducible with a seed. This is the single biggest rubric item. |
| One jump map for snakes and ladders | One lookup, no duplicated logic; direction tells you which it was. |
| Builder that validates, then an immutable `Board` | Invalid boards fail fast at construction, not halfway through a game. See Builder in [Creational Patterns](/learn/notes/creational-patterns/). |
| `EndRule` strategy (enum) | Each house rule is a new constant, not a new `if` in `playTurn`. |
| `MultiDice` composite | "Two dice" is a new object, the game loop is untouched. |
| `playTurn()` returns `TurnResult` | Domain stays free of I/O; tests assert on values. |
| `synchronized` public methods on `Game` | A game is a tiny shared state machine; one lock keeps a turn atomic if a server ever calls it from several threads. Cheap and obviously correct. |
| `playToEnd(maxTurns)` guard | A badly designed board (or bounce-back with huge dice) could loop forever; fail loudly instead. |

**Flow of one turn:** poll the player at the head of the deque → roll → `endRule.advance(from, roll, size)` gives the landing cell → `board.destination(landed)` applies a snake or ladder → store the new position → if it equals `size`, record the winner → put the player at the tail → return a `TurnResult`.

</QA>

<QA q="Reference code — full Java 21 program (Main.java)" level="hard">

One file, package-private classes plus a public `Main`. Compile and run with `javac Main.java && java Main`.

```java
import java.util.*;

// ---------- Dice: the injectable source of randomness ----------

interface Dice {
    int roll();       // one throw (sum of faces if several dice)
    int maxRoll();    // highest possible value, e.g. 6 for one d6
}

final class RandomDice implements Dice {
    private final int faces;
    private final Random random;

    RandomDice(int faces, long seed) {        // seedable => reproducible games
        if (faces < 2) throw new IllegalArgumentException("a die needs at least 2 faces");
        this.faces = faces;
        this.random = new Random(seed);
    }

    RandomDice(int faces) { this(faces, new Random().nextLong()); }

    public int roll() { return 1 + random.nextInt(faces); }
    public int maxRoll() { return faces; }
}

final class FixedDice implements Dice {       // scripted rolls for tests and demos
    private final int[] values;
    private int next;

    FixedDice(int... values) {
        if (values.length == 0) throw new IllegalArgumentException("need at least one value");
        for (int v : values) if (v < 1) throw new IllegalArgumentException("roll must be >= 1: " + v);
        this.values = values.clone();
    }

    public int roll() {
        if (next == values.length)
            throw new IllegalStateException("FixedDice exhausted after " + values.length + " rolls");
        return values[next++];
    }

    public int maxRoll() { return Arrays.stream(values).max().getAsInt(); }
}

final class MultiDice implements Dice {       // Composite: several dice behave like one
    private final List<Dice> dice;

    MultiDice(List<Dice> dice) {
        if (dice.isEmpty()) throw new IllegalArgumentException("need at least one die");
        this.dice = List.copyOf(dice);
    }

    public int roll() { return dice.stream().mapToInt(Dice::roll).sum(); }
    public int maxRoll() { return dice.stream().mapToInt(Dice::maxRoll).sum(); }
}

// ---------- Board: cells 1..size, snakes and ladders as one jump map ----------

final class Board {
    private final int size;
    private final Map<Integer, Integer> jumps;   // start cell -> end cell

    private Board(int size, Map<Integer, Integer> jumps) {
        this.size = size;
        this.jumps = jumps;
    }

    int size() { return size; }
    int destination(int cell) { return jumps.getOrDefault(cell, cell); }

    static Builder builder(int size) { return new Builder(size); }

    static final class Builder {
        private final int size;
        private final Map<Integer, Integer> jumps = new HashMap<>();

        private Builder(int size) {
            if (size < 4) throw new IllegalArgumentException("board too small: " + size);
            this.size = size;
        }

        Builder snake(int head, int tail) {
            if (head <= tail) throw new IllegalArgumentException("snake must go down: " + head + "->" + tail);
            return add(head, tail);
        }

        Builder ladder(int bottom, int top) {
            if (bottom >= top) throw new IllegalArgumentException("ladder must go up: " + bottom + "->" + top);
            return add(bottom, top);
        }

        private Builder add(int from, int to) {
            if (from <= 1 || from >= size)
                throw new IllegalArgumentException("jump cannot start on first or last cell: " + from);
            if (to < 1 || to > size) throw new IllegalArgumentException("jump leaves the board: " + to);
            if (jumps.containsKey(from)) throw new IllegalArgumentException("cell " + from + " already has a jump");
            jumps.put(from, to);
            return this;
        }

        Board build() {
            for (int end : jumps.values())
                if (jumps.containsKey(end))
                    throw new IllegalArgumentException("jump ends on another jump at " + end + " (no chains)");
            return new Board(size, Map.copyOf(jumps));
        }
    }
}

// ---------- Rules for the last few cells (Strategy) ----------

interface EndRule {
    int advance(int from, int roll, int size);   // cell reached before snakes/ladders
}

enum EndRules implements EndRule {
    EXACT_ROLL {       // overshoot => stay put
        public int advance(int from, int roll, int size) { return from + roll > size ? from : from + roll; }
    },
    OVERSHOOT_WINS {   // any roll that reaches or passes the end wins
        public int advance(int from, int roll, int size) { return Math.min(from + roll, size); }
    },
    BOUNCE_BACK {      // walk to the end, then back by the excess
        public int advance(int from, int roll, int size) {
            int target = from + roll;
            return target <= size ? target : Math.max(1, size - (target - size));
        }
    }
}

// ---------- Game state ----------

record Player(String name) {
    Player {
        if (name == null || name.isBlank()) throw new IllegalArgumentException("player name required");
    }
}

enum Jump { NONE, SNAKE, LADDER }

record TurnResult(Player player, int roll, int from, int landed, int to, Jump jump, boolean won) {
    String describe() {
        String s = "%-5s rolls %2d: %3d -> %3d".formatted(player.name(), roll, from, landed);
        if (landed == from) s += " (overshoot, stays)";
        if (jump == Jump.SNAKE) s += " snake! -> " + to;
        if (jump == Jump.LADDER) s += " ladder! -> " + to;
        return won ? s + "  WINS" : s;
    }
}

final class Game {
    private final Board board;
    private final Dice dice;
    private final EndRule endRule;
    private final Deque<Player> turnOrder;
    private final Map<Player, Integer> positions = new HashMap<>();
    private Player winner;
    private int turns;

    Game(Board board, List<Player> players, Dice dice, EndRule endRule) {
        if (players.isEmpty()) throw new IllegalArgumentException("need at least one player");
        if (new HashSet<>(players).size() != players.size())
            throw new IllegalArgumentException("player names must be unique");
        this.board = Objects.requireNonNull(board);
        this.dice = Objects.requireNonNull(dice);
        this.endRule = Objects.requireNonNull(endRule);
        this.turnOrder = new ArrayDeque<>(players);
        players.forEach(p -> positions.put(p, 0));   // 0 = not on the board yet
    }

    synchronized TurnResult playTurn() {
        if (winner != null) throw new IllegalStateException("game over: " + winner.name() + " already won");
        Player player = turnOrder.pollFirst();
        int from = positions.get(player);
        int roll = dice.roll();
        int landed = endRule.advance(from, roll, board.size());
        int to = board.destination(landed);
        Jump jump = to < landed ? Jump.SNAKE : to > landed ? Jump.LADDER : Jump.NONE;
        positions.put(player, to);
        turns++;
        boolean won = to == board.size();
        if (won) winner = player;
        turnOrder.addLast(player);
        return new TurnResult(player, roll, from, landed, to, jump, won);
    }

    synchronized Player playToEnd(int maxTurns) {
        while (winner == null) {
            if (turns >= maxTurns) throw new IllegalStateException("no winner after " + maxTurns + " turns");
            playTurn();
        }
        return winner;
    }

    synchronized Optional<Player> winner() { return Optional.ofNullable(winner); }
    synchronized int positionOf(Player p) { return positions.get(p); }
    synchronized int turns() { return turns; }
}

public class Main {
    static Board standardBoard() {
        return Board.builder(100)
                .snake(99, 54).snake(95, 72).snake(70, 55).snake(52, 42).snake(25, 2)
                .ladder(6, 26).ladder(11, 40).ladder(17, 69).ladder(46, 90).ladder(60, 85)
                .build();
    }

    public static void main(String[] args) {
        System.out.println("== Scripted game: 20 cells, exact roll to win ==");
        Board small = Board.builder(20).ladder(3, 12).snake(17, 4).build();
        Dice scripted = new FixedDice(3, 5, 5, 6, 6, 2, 2, 4, 3, 4, 6, 3, 5);
        Game g1 = new Game(small, List.of(new Player("Asha"), new Player("Ben")), scripted, EndRules.EXACT_ROLL);
        while (g1.winner().isEmpty()) System.out.println(g1.playTurn().describe());

        System.out.println("\n== Seeded game: standard board, 3 players, one d6 (seed 42) ==");
        List<Player> three = List.of(new Player("Asha"), new Player("Ben"), new Player("Chen"));
        Game g2 = new Game(standardBoard(), three, new RandomDice(6, 42), EndRules.EXACT_ROLL);
        Player w2 = g2.playToEnd(10_000);
        System.out.println("winner=" + w2.name() + " after " + g2.turns() + " turns; positions: "
                + three.stream().map(p -> p.name() + "@" + g2.positionOf(p)).toList());

        System.out.println("\n== Extension: two dice, overshoot wins (seed 7) ==");
        Dice twoDice = new MultiDice(List.of(new RandomDice(6, 7), new RandomDice(6, 8)));
        Game g3 = new Game(standardBoard(), three, twoDice, EndRules.OVERSHOOT_WINS);
        System.out.println("winner=" + g3.playToEnd(10_000).name() + " after " + g3.turns() + " turns");

        System.out.println("\n== Invalid board is rejected at build time ==");
        try {
            Board.builder(100).ladder(10, 30).snake(30, 5).build();
        } catch (IllegalArgumentException e) {
            System.out.println("rejected: " + e.getMessage());
        }
    }
}
```

<QA q="Reference tests — plain-Java test harness (Tests.java) and its output" level="hard">

No JUnit needed — a tiny `check` helper is enough in an interview. It covers the core rules, every validation, the end rules, dice, determinism across threads, and a shared game hammered by 8 threads.

```java
import java.util.*;
import java.util.concurrent.*;

public class Tests {
    static int passed, failed;

    static void check(String name, boolean ok) {
        if (ok) passed++; else failed++;
        System.out.println((ok ? "PASS " : "FAIL ") + name);
    }

    static void throwsIt(String name, Class<? extends Throwable> type, Runnable r) {
        try { r.run(); check(name, false); }
        catch (Throwable t) { check(name, type.isInstance(t)); }
    }

    static final Player A = new Player("A"), B = new Player("B");

    static Game game(Board board, EndRule rule, int... rolls) {
        return new Game(board, List.of(A, B), new FixedDice(rolls), rule);
    }

    public static void main(String[] args) throws Exception {
        Board b = Board.builder(20).ladder(3, 12).snake(17, 4).build();

        TurnResult t = game(b, EndRules.EXACT_ROLL, 3).playTurn();
        check("ladder climbs", t.to() == 12 && t.jump() == Jump.LADDER);

        Game g = game(b, EndRules.EXACT_ROLL, 6, 1, 6, 1, 5);   // A: 6,12 -> 17 snake
        g.playTurn(); g.playTurn(); g.playTurn(); g.playTurn();
        TurnResult bite = g.playTurn();
        check("snake bites", bite.landed() == 17 && bite.to() == 4 && bite.jump() == Jump.SNAKE);

        Game turns = game(b, EndRules.EXACT_ROLL, 1, 2, 1, 2);
        List<String> order = new ArrayList<>();
        for (int i = 0; i < 4; i++) order.add(turns.playTurn().player().name());
        check("turns rotate A,B,A,B", order.equals(List.of("A", "B", "A", "B")));

        Game exact = game(b, EndRules.EXACT_ROLL, 6, 1, 6, 1, 6, 1, 5);  // A: 6, 12, 18
        for (int i = 0; i < 6; i++) exact.playTurn();
        check("A reached 18", exact.positionOf(A) == 18);
        TurnResult over = exact.playTurn();                     // 18+5 = 23 > 20
        check("exact roll: overshoot stays", over.to() == 18 && exact.winner().isEmpty());

        Game wins = game(b, EndRules.OVERSHOOT_WINS, 6, 1, 6, 1, 6, 1, 5);
        for (int i = 0; i < 7; i++) wins.playTurn();
        check("overshoot wins", wins.winner().orElseThrow().equals(A) && wins.positionOf(A) == 20);

        check("bounce back 18+5 -> 17", EndRules.BOUNCE_BACK.advance(18, 5, 20) == 17);
        check("bounce back never below 1", EndRules.BOUNCE_BACK.advance(19, 40, 20) == 1);

        Game done = game(b, EndRules.OVERSHOOT_WINS, 20);
        check("first roll can win", done.playTurn().won());
        throwsIt("no turns after game over", IllegalStateException.class, done::playTurn);

        Game ladderToEnd = new Game(Board.builder(10).ladder(4, 10).build(), List.of(A), new FixedDice(4),
                EndRules.EXACT_ROLL);
        check("ladder onto last cell wins", ladderToEnd.playTurn().won());

        throwsIt("snake must go down", IllegalArgumentException.class, () -> Board.builder(20).snake(3, 9));
        throwsIt("ladder must go up", IllegalArgumentException.class, () -> Board.builder(20).ladder(9, 3));
        throwsIt("no jump on last cell", IllegalArgumentException.class, () -> Board.builder(20).snake(20, 2));
        throwsIt("no jump off the board", IllegalArgumentException.class, () -> Board.builder(20).ladder(5, 25));
        throwsIt("one jump per cell", IllegalArgumentException.class,
                () -> Board.builder(20).ladder(5, 9).snake(5, 2));
        throwsIt("no chained jumps", IllegalArgumentException.class,
                () -> Board.builder(20).ladder(5, 9).snake(9, 2).build());
        throwsIt("duplicate player names", IllegalArgumentException.class,
                () -> new Game(b, List.of(A, new Player("A")), new FixedDice(1), EndRules.EXACT_ROLL));
        throwsIt("needs a player", IllegalArgumentException.class,
                () -> new Game(b, List.of(), new FixedDice(1), EndRules.EXACT_ROLL));
        throwsIt("fixed dice exhausts loudly", IllegalStateException.class,
                () -> { Dice d = new FixedDice(1); d.roll(); d.roll(); });
        throwsIt("max-turn guard", IllegalStateException.class,
                () -> new Game(b, List.of(A), new FixedDice(1, 1, 1),
                        EndRules.EXACT_ROLL).playToEnd(3));

        Dice two = new MultiDice(List.of(new FixedDice(3), new FixedDice(4)));
        check("multi dice sums", two.roll() == 7 && two.maxRoll() == 7);
        Dice seeded = new RandomDice(6, 1);
        boolean inRange = true;
        for (int i = 0; i < 10_000; i++) { int r = seeded.roll(); inRange &= r >= 1 && r <= 6; }
        check("random die stays in 1..6", inRange);

        // Determinism: same seed => same game, even when many games run in parallel.
        int games = 500;
        Map<Integer, String> sequential = new HashMap<>();
        for (int s = 0; s < games; s++) sequential.put(s, playSeeded(s));
        Map<Integer, String> parallel = new ConcurrentHashMap<>();
        try (ExecutorService pool = Executors.newVirtualThreadPerTaskExecutor()) {
            for (int s = 0; s < games; s++) {
                int seed = s;
                pool.submit(() -> parallel.put(seed, playSeeded(seed)));
            }
        }
        check("500 seeded games identical in parallel and sequential", sequential.equals(parallel));

        // One shared game hammered by 8 threads: synchronized playTurn keeps state consistent.
        Game shared = new Game(Main.standardBoard(), List.of(A, B), new RandomDice(6, 99), EndRules.EXACT_ROLL);
        CountDownLatch go = new CountDownLatch(1);
        List<Thread> threads = new ArrayList<>();
        for (int i = 0; i < 8; i++) {
            Thread th = Thread.ofPlatform().start(() -> {
                try { go.await(); } catch (InterruptedException e) { return; }
                while (true) {
                    try { shared.playTurn(); } catch (IllegalStateException over2) { return; }
                }
            });
            threads.add(th);
        }
        go.countDown();
        for (Thread th : threads) th.join();
        Game replay = new Game(Main.standardBoard(), List.of(A, B), new RandomDice(6, 99), EndRules.EXACT_ROLL);
        replay.playToEnd(100_000);
        check("shared game under 8 threads matches single-threaded replay",
                shared.winner().equals(replay.winner()) && shared.turns() == replay.turns());

        System.out.printf("%n%d passed, %d failed%n", passed, failed);
        if (failed > 0) System.exit(1);
    }

    static String playSeeded(int seed) {
        Game g = new Game(Main.standardBoard(), List.of(A, B, new Player("C")), new RandomDice(6, seed),
                EndRules.EXACT_ROLL);
        Player w = g.playToEnd(100_000);
        return w.name() + "/" + g.turns();
    }
}
```

## Self-review checklist

Tick these honestly before reading the reference in detail:

- [ ] A full game runs from `main` and stops at exactly one winner.
- [ ] My game takes a `Dice` through the constructor; I can run it with fixed rolls.
- [ ] My random dice accepts a seed, and the same seed gives the same game.
- [ ] Snakes and ladders go through one code path, not two duplicated loops.
- [ ] The end-of-board rule is a pluggable object, not a boolean flag inside the loop.
- [ ] Two dice can be added without editing the game class.
- [ ] Invalid boards throw a clear exception at construction time.
- [ ] Calling `playTurn` after the game is over throws instead of silently moving players.
- [ ] There's a guard against a game that never ends.
- [ ] Domain classes don't print; `main` (or tests) does.
- [ ] I have at least 5 tests: ladder, snake, overshoot, win, invalid board.
- [ ] I wrote down my assumptions (start at 0, exact roll, first winner ends the game).

<MCQ q="Why should the game receive a Dice object through its constructor instead of calling new Random() internally?" options={["Random is not thread-safe, so it must never be created inside a class", "So tests and demos can inject a scripted or seeded dice and get predictable results", "Because Java requires all random sources to be singletons", "It makes each roll faster because the object is reused"]} answer={1}>

Injecting the dependency lets a test pass a fixed sequence of rolls, and lets a demo pass a seeded `Random`. `java.util.Random` is actually thread-safe (though contended); there is no singleton requirement; and speed has nothing to do with it.

</MCQ>

<MCQ q="Two java.util.Random instances are created with the same seed and receive the same sequence of nextInt calls. What happens?" options={["They return different numbers because Random mixes in the system time", "They return the same numbers only on the same JVM vendor", "They return identical sequences — the algorithm is specified so this holds on every Java implementation", "It depends on whether the calls happen on the same thread"]} answer={2}>

The `Random` Javadoc guarantees identical sequences for the same seed and the same calls, and requires every Java implementation to use the specified algorithm so the guarantee is portable. Only the no-argument constructor picks a varying seed.

</MCQ>

<MCQ q="What is the cleanest way to support rolling two dice in the reference design?" options={["Add an int diceCount field to Game and loop inside playTurn", "Create a MultiDice that holds several Dice and is itself a Dice returning their sum", "Subclass Game as TwoDiceGame and override playTurn", "Call dice.roll() twice wherever a roll is needed"]} answer={1}>

A composite that implements the same interface means `Game` is unchanged — it still calls `roll()` once. A count field or a subclass edits or duplicates the game loop; calling `roll()` twice scatters the rule.

</MCQ>

<MCQ q="A board has a ladder from 10 to 30 and a snake from 30 to 5. Why does the reference reject it?" options={["Snakes may never start on a multiple of 10", "A jump ends on another jump's start, creating a chain — the rules for chained moves are ambiguous and can form loops", "Ladders must be shorter than snakes", "Cell 30 is too close to the end of the board"]} answer={1}>

Landing on 10 would take you to 30, which is a snake head — do you follow it? Different house rules disagree, and a ladder 5-to-10 plus snake 10-to-5 could loop forever. Rejecting chains at build time removes the ambiguity. The other options are made-up rules.

</MCQ>

<MCQ q="With the EXACT_ROLL end rule on a 20-cell board, a player on cell 18 rolls a 5. Where do they end up?" options={["Cell 20, and they win", "Cell 17, bouncing back by the excess", "Cell 18 — an overshoot means no move", "Cell 3, wrapping around the board"]} answer={2}>

Exact roll means you must land precisely on the last cell; overshooting leaves you where you were. Capping at 20 is OVERSHOOT_WINS, reflecting to 17 is BOUNCE_BACK, and wrapping isn't a standard rule.

</MCQ>

<MCQ q="Why does playTurn return a TurnResult record instead of printing the move?" options={["Records are faster to print than strings", "Printing from domain code is forbidden by the Java language", "It keeps the domain free of I/O so tests can assert on the outcome and any UI can render it", "So the result can be stored in the board's jump map"]} answer={2}>

Returning a value separates game logic from presentation: `main` prints it, tests assert on fields like `to()` and `jump()`, and a web or CLI front end could format it differently. Nothing in Java forbids printing — it's a design choice.

</MCQ>

<MCQ q="An interviewer asks for 'a roll of 6 gives another turn'. What is the smallest correct change to the reference?" options={["Make every player roll twice", "When roll equals dice.maxRoll(), put the current player back at the head of the turn deque instead of the tail", "Add a new Board.Builder method called bonus()", "Change the dice to have 7 faces"]} answer={1}>

Turn order lives in the deque, so the rule is a one-line choice of `addFirst` versus `addLast` (plus a cap on consecutive bonus turns if asked). Using `maxRoll()` instead of the literal 6 keeps it working with other dice. Boards and dice faces are unrelated.

</MCQ>

<MCQ q="Why can a seeded game still be deterministic when Game.playTurn is called from 8 threads at once in the test?" options={["Because synchronized makes threads run in a fixed order", "Because each whole turn — dequeue, roll, move, re-queue — runs under one lock, so the sequence of rolls and turn order is the same as a single-threaded run", "Because Random is thread-local by default", "It isn't deterministic; the test just got lucky"]} answer={1}>

Which thread executes a given turn varies, but every turn is atomic and the next turn always reads the state the previous one left. So the k-th roll always goes to the same player at the same position. `synchronized` doesn't order threads, and `Random` is not thread-local.

</MCQ>

## TL;DR

- **Rubric heavyweights:** a full game that ends correctly, and **injectable dice** (interface + seeded random + fixed sequence). Those two alone are 4 of 10 points.
- **Model:** `Board` (size + one jump map, built and validated by a Builder) · `Dice` (interface) · `Player` (record) · `Game` (turn deque + positions + winner) · `TurnResult` (record).
- **Patterns, only where variation is asked for:** Strategy for the end rule, Composite for multiple dice, Builder for board validation.
- **Validate the board up front:** snake goes down, ladder goes up, no jump on first or last cell, one jump per cell, no chained jumps.
- **Edge cases to say out loud:** exact-roll overshoot, ladder onto the last cell, play after game over, a game that never ends (max-turns guard), duplicate player names.
- **Extensions are cheap when the design is right:** two dice is a new object, a house rule is a new strategy, extra turn on max roll is `addFirst` vs `addLast`.
